## Open the presentation

Open apex-eacl-briefing.html directly in a modern browser.

- Use Previous / Next, the numbered footer navigation, the left/right arrow keys, Page Up/Page Down, Home, or End.
- On the comparison slide, choose an evaluator tab and select evidence-turn buttons to highlight the shared transcript.
- Without JavaScript, all 15 sections remain visible in order.
- To create a handout or PDF, use the browser’s print dialog in landscape mode. Print styles expand the transcript, literature, and evaluator panels.
- The notes field on the final slide is local-only and has no save or submit action.
